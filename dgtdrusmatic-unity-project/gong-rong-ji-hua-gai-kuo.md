# 共荣计划概括

DGTD工业发现了这个种族的高度先进（或是曾经高度先进）的技术，他们愿意花费大量的资金和时间来扶持这一个可爱的物种，但同时也对锈羽梨子们提出了要求，他们的技术需要能够反哺DGTD，为此组建了新的公司名为Sperria，用于实际上管理和资助锈羽的发展和将技术回收和控制在一个第三方手里



目前该项计划处于初期的早期阶段，该计划的核心目标是为了促进锈羽文明与勒柯文明的科技进步，该计划分为数个阶段，根据实地考察的情况进行不同的调整

> 我们像Icarus一样，触及了天空的禁忌，融化了翅膀，却获得了自由

阶段一：

建立锈羽与勒柯之间的桥梁，需要小心地收集当地居民的情报，建立第一次接触，向他们表面自己的来意以及展示自己的资源，并和当地居民签订共荣协议



阶段二：

根据共荣协议，在锈羽区域内建设Sperria离岸公司分部，建设基础设施，设立Sperria驻锈羽办事处，派遣常驻外交大使和员工等驻扎，推动双方文化交流



阶段三：

建设物资通道，为锈羽区域带去物资技术等必要资源，同时进一步推进锈羽高新园区建设，进一步推进双方文明的交流



阶段四：

锈羽区域基本建设完毕，进入正式的研究阶段，至此共荣计划初期目标达到
